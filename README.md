# Despesas Pessoais 💰

> **Status do Projeto:** Em desenvolvimento 🚧

Um aplicativo de finanças pessoais desenvolvido com **Flutter**. O objetivo deste aplicativo é permitir que o usuário registre, acompanhe e gerencie suas despesas diárias de forma simples e intuitiva.

## 🚀 Funcionalidades

### ✅ Já implementadas
- Listagem de transações (despesas) com título, valor e data.
- Formulário para adicionar novas transações.
- Modal inferior (Bottom Sheet) para exibir o formulário.
- Tema customizado com fontes personalizadas (*Quicksand* e *OpenSans*).
- Tratamento de interface quando a lista de transações está vazia (imagem e texto informativos).

### ⏳ Em breve
- Gráfico dinâmico mostrando as despesas dos últimos dias.
- Exclusão de transações.
- Persistência de dados.
- Filtros por data.

## ⚙️ Como executar o projeto

Para rodar este projeto na sua máquina, você precisa ter o ambiente Flutter configurado.

1. Clone este repositório:
   ```bash
   git clone https://github.com/caioeduardoml/Despesas-Pessoais.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Despesas-Pessoais
   ```
3. Instale as dependências:
   ```bash
   flutter pub get
   ```
4. Execute o aplicativo (com um emulador Android/iOS aberto ou dispositivo conectado):
   ```bash
   flutter run
   ```
